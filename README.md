# larc-uwindsor.github.io

A plain static website for the LARC UWindsor GitHub Pages site.

## Structure

- `index.html` – Main page content
- `styles.css` – Site styling
- `.github/workflows/jekyll-gh-pages.yml` – GitHub Pages deployment workflow

## Local preview

Because this is a plain static site, you can open `index.html` directly in a browser, or run a local static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
